# Support

For questions about project scope, licensing or contributions, contact Miroslav Šotek, ANULUM, at protoscience@anulum.li.

The repository foundation is under construction. There is no released package, multiphysics field-solving service, installation support commitment or qualified electromagnetic or thermal model. Do not rely on planned records for a signal-integrity, power-integrity, thermal-runaway or mechanical-warpage decision.

For a technical report, provide the exact source revision, runtime environment, expected behaviour and minimal legally shareable input; never attach a customer design, a confidential foundry stack-up, a proprietary package CAD model or a capture that is not public. Keep original outcomes and state which references or environments were unavailable. See [contributing](CONTRIBUTING.md).
